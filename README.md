# Fitness & Workout Planner App 💪

A Flutter-based fitness app with AI-powered workout suggestions and progress tracking.

## Features
- Plan and schedule workout routines
- Track exercise progress with visual charts
- AI-based smart workout generation
- Personalized fitness suggestions
- Fitness goal management

## Tech Stack
- Flutter & Dart
- Firebase (Authentication + Realtime Database)
- AI Integration (Smart Suggestions)
- Charts & Analytics (fl_chart)
